# Universal Production Tools — 한 장 요약

**레퍼런스 영상의 카메라 구도를 언리얼 Level Sequence로 재현하는 UE 5.7 에디터 플러그인**
개인 프로젝트 · C++ 49 파일, Python 28 파일 · [저장소](https://github.com/heewonle/universal-production-tools)

## 무엇을 만들었나

영상을 넣으면 샷을 나누고, 각 샷의 인물 위치·크기·카메라 앵글을 읽어, 레벨의 캐릭터로 같은 구도의
시퀀스를 만듭니다. 클라우드 API 없이 로컬 포즈 분석(YOLOX + RTMPose, ONNX CPU)만으로 동작합니다.

- 샷 분할(PySceneDetect) → 인물 검출·관절 추정 → 구도 해석 → 카메라 배치 → Level Sequence 생성
- 세로 영상·레터박스·고정 자막 처리, 유튜브 등 링크 입력, 프롬프트 기반 유사 영상 검색
- 투샷·어깨 너머(OTS) 구도 해석, 샷 단위 재편집(같은 시퀀스를 그 자리에서 갱신)

## 핵심: 정확도를 재는 장치를 먼저 만들었다

이 프로젝트에서 가장 공들인 부분은 기능이 아니라 **검증 체계**입니다.
엔진 안에서는 카메라와 뼈 위치를 정확히 알 수 있다는 점을 이용해, 에디터에서 **정답 데이터를 직접 촬영**하고
생성 결과를 같은 분석기로 다시 측정해 회귀 검사(현재 **11개 스위트**)로 잠갔습니다.

```
Tools/eval/editor/upt_capture_*.py   에디터에서 정답 촬영(뼈 위치·화면 투영값)
Tools/eval/eval_*.py                 정답 대비 오차 측정
Tools/eval/run_regression.py         전체 실행 + baseline.json 기준 비교
```

## 그 장치로 실제로 잡은 것

| 문제 | 어떻게 드러났나 | 결과 |
|---|---|---|
| 어깨 너머 샷이 세로로 프레임을 벗어남 | 솔버는 "성공" 보고, 렌더에는 앞사람이 없음 | 가로만 검사하던 조건에 세로 조건·카메라 높이 탐색 추가 |
| 검증기가 잘린 인물 위치를 9% 오측정 | 정답(카메라 조준값)에 대고 측정 규칙 3종 채점 | 평균 오차 0.035 → **0.012** |
| 어깨 너머 자동 검증이 원리적으로 불가능 | 인물 검출기·분할 모델 모두 0개 검출 | 앞사람만 숨기고 한 장 더 찍어 차이 비교 — 모델 없이 판정 |
| 영상 3D 관절의 깊이가 잡음 | 깊이 상관 0.215, 오른손 −0.35, 양발 0.0 | **애니메이션 굽기 중단**하고 한계를 문서화 |

## 스스로 기각한 것도 남겼다

- 크기 점수를 "정확한 기하값"으로 바꿨더니 **오히려 나빠져** 되돌렸습니다(레퍼런스 쪽도 같은 추정기로
  재기 때문에 한쪽만 정확하게 만들면 편향이 깨집니다).
- 체형 보정 한계를 넓혀 얻은 개선폭(9.8%→7.3%)이 **재촬영에서 재현되지 않아** 문서를 정정했습니다.
  변경 자체는 어떤 데이터에서도 나빠지지 않아 유지했지만, "큰 개선"이라는 표현은 철회했습니다.
- 통계적으로 나아 보이던 측정 규칙(중앙값 최적)을 적용했다가 **실제 점수가 떨어져** 되돌렸습니다.

## 이 프로젝트가 보여주는 것

- **엔진 내부 지식을 검증 자산으로 전환**: 뼈·카메라·바운즈를 정답으로 삼아 시험 세트를 만드는 접근
- **UE 에디터 자동화의 실전 함정 처리**: 에디터 월드는 애니메이션을 평가하지 않음, 시퀀서 스폰어블,
  틱 기반 비동기 처리, SceneCapture `ShowOnlyActors`/`HiddenActors` 활용
- **C++ / Python 경계 설계**: 구도 계산·시퀀스 생성은 C++, 영상 분석·측정은 Python, 콘솔 명령으로 헤드리스 실행
- **한계를 숫자로 말하기**: 되는 것과 안 되는 것을 같은 기준으로 보고

## 기술 스택

UE 5.7 (C++, Slate, MovieScene, Sequencer 자동화) · Python (OpenCV, ONNX Runtime, NumPy) ·
YOLOX / RTMPose / RTMW3D · PySceneDetect · yt-dlp · UE 5.8 MetaHuman Animator(얼굴 캡처 경로)
